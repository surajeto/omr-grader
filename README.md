# ตรวจข้อสอบ (OMR บนมือถือ)

**ใช้งาน:** https://omr-grader-nine.vercel.app · push ขึ้น `main` แล้ว Vercel deploy ใหม่อัตโนมัติ

เว็บแอปตรวจกระดาษคำตอบ ม.อุบลฯ (60 ข้อ 4 ตัวเลือก) ด้วยกล้องมือถือ ไม่ต้องกดถ่าย ระบบถ่ายเองเมื่อภาพนิ่งและคมชัด

## วิธีใช้
1. **＋ ชุดใหม่** → ใส่วิชา, จำนวนข้อ, เฉลย (แตะ ก ข ค ง / พิมพ์ `กขคง…` / หรือ **สแกนจากกระดาษ** ที่ฝนเฉลยไว้)
2. **เริ่มตรวจ** → วางกระดาษให้เห็นสัญลักษณ์ 4 มุม ถือนิ่ง ระบบจะตรวจและแสดงคะแนนเอง
3. ยกแผ่นออก วางแผ่นต่อไป (ถ้าสแกนรหัสเดิมซ้ำ ระบบจะอัปเดตคะแนนแทนการเพิ่มแถวใหม่)
4. หน้าผลคะแนน → แตะแถวเพื่อแก้ชื่อ/ดูข้อผิด · ส่งออกเป็น **CSV** หรือ **Excel**

## ชื่อนักศึกษา
- รหัสนักศึกษา, กลุ่มเรียน, เลขที่นั่งสอบ อ่านจากวงที่ฝน
- ชื่อ: (1) วางรายชื่อ `รหัส,ชื่อ-สกุล` ในหน้าตั้งค่า → เติมชื่อจากรหัสอัตโนมัติ (แม่นที่สุด)
  (2) ใส่ Claude API key → ให้ AI อ่านชื่อลายมือ (3) ถ้าไม่ตั้งค่า แอปจะเก็บภาพช่องชื่อไว้ให้ดู/พิมพ์เอง

## การติดตั้ง (ต้องเป็น https เพื่อใช้กล้องมือถือ)
- ขึ้นอยู่บน Vercel แล้ว (ตั้งค่าใน `vercel.json`) แก้โค้ดแล้ว push ขึ้น `main` เว็บจะอัปเดตเอง
- เปิดลิงก์บนมือถือ → "เพิ่มไปยังหน้าจอโฮม" ใช้เหมือนแอป (ครั้งแรกโหลดตัวตรวจ ~10MB แล้วแคชไว้)
- ไฟล์ที่ต้องใช้: `index.html app.js omr.js sw.js manifest.webmanifest icon.svg` (`test.html` และรูป .jpg ใช้ทดสอบเท่านั้น)

## ส่งคะแนนขึ้น Google Sheets ทันที (ไม่บังคับ)
ใน Google Sheet → ส่วนขยาย → Apps Script วางโค้ดนี้ แล้ว Deploy เป็น Web app (Execute as: Me, Who has access: Anyone) นำ URL ไปใส่ในหน้าตั้งค่า

```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getSheetByName(d.subject) || ss.insertSheet(d.subject);
  if (sh.getLastRow() === 0) sh.appendRow(['เวลา', 'รหัสนักศึกษา', 'ชื่อ-สกุล', 'กลุ่ม', 'เลขที่นั่ง', 'คะแนน', 'เต็ม', 'คำตอบ']);
  sh.appendRow([d.at, d.sid, d.name, d.group, d.seat, d.score, d.total, d.answers]);
  return ContentService.createTextOutput('ok');
}
```
